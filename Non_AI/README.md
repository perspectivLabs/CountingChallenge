# Non-AI counting — OpenCV

## Problem and method

Count hardware instances in each original photograph without a neural network. The
script creates grayscale and HSV candidate foreground masks, including Otsu and
adaptive thresholds in both polarities and a border-background estimate. Gaussian
blur, morphological opening/closing, connected components, distance transforms, and
watershed produce candidate instance regions.

Each candidate is filtered and scored using foreground coverage relative to a 0.06
target plus log-area dispersion. A safeguard rejects unusually high counts whose
average instance area is exceptionally small, reducing catastrophic fragmentation.
The best-scoring candidate supplies the image count. The method is sensitive to
lighting, shadows, internal holes, object overlap, and watershed seed quality; dense
objects may be under- or over-segmented.

The output mask stores a distinct 16-bit instance ID for each counted region. The
overlay outlines and numbers those same regions, so its detections correspond to the
CSV count.

## Install and run

From the project root:

```powershell
python -m pip install -r Non_AI\requirements.txt
python Non_AI\non_ai_counting.py --input "<DATASET_ROOT>" --output Non_AI\final_output
```

`<DATASET_ROOT>` is the extracted dataset directory containing the two image folders.
Input images are discovered recursively and remain outside the submission project.

## Outputs

`Non_AI/final_output/` contains:

- `predictions.csv` with one filename, count, and processing status per input;
- one 16-bit instance-ID `_mask.png` and numbered `_overlay.jpg` per image;
- `evaluation.csv`, generated by the shared evaluator.

Results are grouped by source image-folder name, and prediction rows retain original
input paths.

## Evaluation

Run the shared evaluator from the project root:

```powershell
python evaluate_counts.py `
  --predictions Non_AI\final_output\predictions.csv `
  --ground-truth ground_truth.csv `
  --output Non_AI\final_output\evaluation.csv
```

For positive true counts, per-image relative accuracy is
`1 - abs(predicted - true) / true`; overall relative accuracy is the macro mean across
scored verified images. The report also includes MAE, MAPE, exact matches, and
verified/unverified status. Provisional rows in `ground_truth_plan.csv` are not read
by the evaluator.

## Current results and limitations

On the current eight verified images: mean relative count accuracy is **85.39%**,
MAE **2.375**, MAPE **14.61%**, and exact match **2/8 (25.00%)**. Seventeen of 25
images remain unverified. Therefore, the >95% target is not demonstrated, either on
the verified subset or across the complete dataset.

Traditional thresholding is fast and transparent, but touching screws may merge,
specular edges may fragment, and watershed may place boundaries incorrectly.
Predictions and visual outputs are not ground truth.
