# Counting Challenge: Biplab Bag

Count the items (screws, bolts, nuts) in each image and overlay their masks, solved twice:

| Folder | Approach | Mean counting accuracy (25 images) |
|---|---|---|
| [`Non_AI/`](Non_AI/README.md) | Classical image processing: OpenCV, SciPy, scikit-image | **99.70 %** (21 / 25 exact) |
| [`AI/`](AI/README.md) | YOLO11s-seg fine-tuned on synthetic copy-paste data | **99.84 %** (22 / 25 exact) |

Both are above the required 95 % on every single image. Worst image: Non-AI 95.92 %, AI 97.96 %.

Python 3.10.11. Each folder has its own `requirements.txt` and README.

## Quick start

```bash
# Non-AI
cd Non_AI && pip install -r requirements.txt
python count_non_ai.py -i <ScrewAndBolt folder> <Screws folder> -o outputs --save-masks

# AI (needs weights/best.pt - see AI/README.md for training)
cd ../AI && pip install -r requirements.txt
python count_ai.py -i <ScrewAndBolt folder> <Screws folder> -o outputs --save-masks

# compare both with the ground truth
cd .. && python evaluate.py --pred Non_AI/outputs/counts.csv AI/outputs/counts.csv
```

Accuracy per image = 1 − |predicted − true| / true.

## How the ground truth was made

No counts were supplied (apart from the `43` in `img1_43_nosy.jpg`), so `ground_truth.csv` was built by hand:

1. **Screws.** Each photo was split into connected blobs. Every blob that was not clearly a single screw was cropped, zoomed (full 12 MP resolution for large clusters) and counted screw by screw.
2. **Nuts.** Every detected through-hole was drawn on the image. Zoomed tiles were checked so that each nut had exactly one hole mark, and every region where hole count and area disagreed was inspected. One nut standing on its edge, with no visible hole, was found this way.
3. **Consistency.** Each set is the same parts re-scattered between photos, and the counts agree across all of them: 193 ×3, 98 ×6, 354 ×5, 43 ×7, 21 ×2, 10 ×2.
4. **Independent check.** A blind recount with [`tools/manual_count.py`](tools/manual_count.py) (raw photo, click every item) covered 8 photos, one or more per set. Every cluster where the recount and the reference disagreed was reviewed side by side. This corrected the first-pass counts of the mixed set from 100 / 99 / 99 to 98.

**Limitations.** The counts were made by visual inspection, and the independent blind recount covers 8 of the 25 photos. The cluster review used the Non-AI blob split as its starting point, which may slightly favour that method.
