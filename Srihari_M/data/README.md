# Sample Images

This directory is the local input set used for examples with the Non-AI counting script. The images are not included in Git. Add or download readable image files here, or pass any other image file/folder to the script.

From the repository root, process the images with:

```bash
python3 Srihari_M/Non_AI/Non_AI_Counting.py --input Srihari_M/data --output Srihari_M/Non_AI/Output/run_01 --upto 8
```

The output path contains per-stage images and `counts.csv`; see [Non-AI README](../Non_AI/README.md) for what each result means.
