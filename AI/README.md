# AI counting — FastSAM-S

## Problem and method

Count hardware instances in each original photograph and provide visual evidence of
the detections. This AI solution uses Ultralytics' pretrained FastSAM-S model; it does
not train or fine-tune a model and does not assign hardware classes.

Images whose longest side exceeds 1600 pixels are reduced for inference. FastSAM
produces polygon mask proposals. The pipeline rasterizes proposals, rejects masks
that are too small, cover an implausibly large part of the image, or have very low
bounding-box fill. Near-duplicate proposals are merged using overlap thresholds.
Masks larger than 1.5 times the median retained-mask area are considered for
watershed splitting; a split is accepted only when multiple distance-transform peaks
produce pieces with adequate area and coverage. This threshold was lowered from 4
after verified sparse images showed merged touching screws; the verified-set mean
relative accuracy improved from 85.51% to 89.26%. Splitting remains conservative and
may still miss or over-split objects.

## Install and run

From the project root:

```powershell
python -m pip install -r AI\requirements.txt
python AI\ai_counting.py --input "<DATASET_ROOT>" --output AI\final_output
```

`<DATASET_ROOT>` is the extracted dataset directory containing the two image folders.
FastSAM downloads `FastSAM-s.pt` on first use; `--model <checkpoint>` selects another
compatible checkpoint.

## Outputs

`AI/final_output/` contains:

- `predictions.csv` with one filename, count, and processing status per input;
- one 16-bit instance-ID `_mask.png` and numbered `_overlay.jpg` per image;
- `evaluation.csv`, generated by the shared evaluator.

The output images are grouped under the source image-folder name. Prediction rows
retain the original input paths.

## Evaluation

Run the shared evaluator from the project root:

```powershell
python evaluate_counts.py `
  --predictions AI\final_output\predictions.csv `
  --ground-truth ground_truth.csv `
  --output AI\final_output\evaluation.csv
```

Relative accuracy per positive-count image is
`1 - abs(predicted - true) / true`; overall relative accuracy is the macro mean across
scored verified images. The report also includes MAE, MAPE, exact matches, and
verified/unverified status. Provisional rows in `ground_truth_plan.csv` are not read
by the evaluator.

## Current results and limitations

On the current eight verified images: mean relative count accuracy is **89.26%**,
MAE **1.750**, MAPE **10.74%**, and exact match **3/8 (37.50%)**. Seventeen of 25
images remain unverified. Therefore, the >95% target is not demonstrated, either on
the verified subset or across the complete dataset.

FastSAM is class-agnostic. It can miss small objects, merge touching objects, or
propose multiple masks for one object. Dense piles and occlusions are particularly
difficult. Masks/overlays require visual review; predictions must not be used as
ground truth.
